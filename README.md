Documentacion
El sistema administra los stands de la FILEY mediante una lista simplemente ligada ordenada por área (ancho x largo) de menor a mayor, con un diseño modular estructurado en stand.h, stand.c y main.c, para mantener la lista en orden sin duplicar código, la función actualizarStand elimina y reinserta el nodo si sus medidas cambian, utilizando punteros dobles (Stand **cabeza) para actualizar la cabeza de forma segura, siendo el mayor reto sintetizar el funcionamiento del código en el video, por lo que fue necesario apoyarse en un guion estructurado para organizar las ideas con claridad antes de la demostración en consola.
